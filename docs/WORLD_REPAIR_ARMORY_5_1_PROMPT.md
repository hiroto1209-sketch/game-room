# GAME ROOM — WORLD REPAIR / PARTY HOUSE ARMORY 5.1
## 完全実装修正プロンプト（現状コード検証済みの問題点に基づく）

あなたは `hiroto1209-sketch/game-room` の技術責任者として、ユーザーが撮影した2026-10-10のiPhone Safari録画とスクリーンショットに見られるワールド不安定問題を、見た目と当たり判定の両方から根本解決してください。

**既存の世界、写真共有、3人同室、看板、オセロ、HP、ワールド全域ブラスター、ピースモードを破壊しないこと。** iPhoneの滑らかな移動と軽量さを最優先。新しい木揺れ、草揺れ、重い水面シェーダー、追加のリアルタイムライトは禁止。

## 0. 既存コードで特定した原因（当て推量をせず最初に再確認）

1. `shared/worldRules.js` の `OUTDOOR.minX=8` と `OutdoorWorld.ts` の範囲 `x=8..104` が原因で、パーティハウスの背面と西側に外部地面が存在しない。建物が空中に浮く。
2. 旧 `OutdoorWorld.makeChunk` の地面は `groundHeightAt(x,z)` で池中央にも生成され、池の水面が低い `y=.02` にあるため水が覆い隠される。一方、`insidePond` 衝突は残るため透明な壁に見える。
3. `#top-bar{pointer-events:none}` に対し、`#secret-trigger` に `pointer-events:auto` がないので、ロゴの5連打が操作できない。
4. 屋内の従来の末端廊下 `z=18` が壁で閉じており、秘密コードを入力する建築上の装置がない。
5. クライアント/Workerで新しい地形範囲や壁の規則が異なると `Invalid movement` が再発する。

## 1. 地面が途切れない世界に再設計

- 既存の外部植物チャンクの座標（`centerX=16+16*cx`）は変えない。
- 外部マップ境界を家の背面・西側へ延長し、未覆域 `x=-24..8` に継ぎ目のない地面を追加。
- 屋内床より下へ地面を配置し、床を重ねてもチラツキが発生しないようにする。
- 3Dで地面の表示範囲、サーバー有効移動範囲、各種境界を同じ `shared/worldRules.js` で定義する。
- 扉、ハウス背面、西側、拡張室の移動テストを作成する。無制限の座標検証は禁止。

## 2. 池と当たり判定の整合

- `POND` 定数を視覚表現と衝突判定の共通根拠にする。
- 水面の下に静的な池底を作り、頂点のある地形メッシュが水面を覆わないようにする。
- 水面はリアルタイム反射なしの軽量マテリアルとし、岸の地面との高低差を制御する。
- 水面外周に自然な岸を見せ、見えていない位置にコライダーだけが残る状態を作らない。
- 既存の池へ進めない仕様を維持。将来水に入る仕様へ変更する場合は水中衝突と移動処理を同時に変更する。
- 近距離と遠距離、チャンク入れ替え時、3人オンライン時に視覚と当たり判定の一致を検証する。

## 3. パーティハウス拡張＋ゲーム内武器ATM

- 既存のパーティールームと中央の大看板、モニター、オセロ床、アーケードを動かさない。
- 元の廊下 `z=8..18` を後方へ延長し、`z=18..26` の広いARMORY室につなげる。
- 元の `z=18` の壁を通行可能なポータルへ改造し、拡張室には床・屋根・壁・案内表示を設ける。
- 拡張室内の `x≈3,z≈23.4` へATM状の視認性の高い端末を置く。
- 端末へ近づくと既存の「**あそぶ**」が現れ、押すと `NEON777` 入力UIが開く。
- 現行のCloudflare `unlock_weapon` で解放判定し、クライアント自身が勝手に銃解放を確定しない。
- ロゴを5回押す旧ショートカットは任意で維持してよいが、**ATM単体で全機能が完結すること**。
- 新しい部屋へ行くために隠しコマンド自体は不要。部屋は全参加者に開放する。
- iPhoneの移動スティック・視点・操作・ジャンプ・射撃ボタンのタッチ干渉を起こさない。

## 4. 性能・安定性

- 風のアニメ、装飾用の毎フレーム更新、新規有料APIなどは導入しない。
- `InstancedMesh` を継続利用し、地形は固定低ポリゴン。水面反射や新しい多数の動的光源を使わない。
- 位置補正はサーバーが最後に承認した位置を返す。制限を解除せず正しい通路だけ通れるようにする。
- クライアントのマップ表現とWorkerの位置バリデーションを同じ定数で更新する。
- 見えない池判定と家の背後の浮遊感を実機の画面で確認し、画像のスクリーンショットで比較する。
